A university wants to develop a simple Student Information System using JavaScript. Write a JavaScript program that asks the user to enter a student's name, age, CGPA, student status, and grade, stores the information using appropriate variables and data types, and displays the entered information. The program should also store three course names Web Technology, OOP, and Database in an array and display them using a loop. The program should ask the user to enter marks and determine the student's grade based on the following conditions: marks = 80 as A+, marks = 70 as A, marks = 60 as B, and otherwise F. Create a function named showStudent() that receives the student's name and age as parameters and displays them. Finally, create an array to store the names of three students using user input and display all the student names using a loop.
